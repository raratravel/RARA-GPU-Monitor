# RARA GPU Monitor

Free NVIDIA GPU Monitoring Application for Windows.

Developed by Rara Exposers Private Limited.

RARA GPU Monitor is a lightweight Windows desktop application designed to display NVIDIA GPU performance, temperature, VRAM usage, power consumption, fan statistics and live performance graphs.

## Features

- Real-time NVIDIA GPU monitoring
- GPU temperature and utilization
- Dedicated GPU memory (VRAM) monitoring
- Power consumption and fan statistics
- Live performance graphs
- GPU process information where supported
- Built-in local web dashboard
- Web server ON/OFF controls
- Automatic and fixed port selection
- Customizable refresh interval
- Dark-themed desktop interface

## Download

Download the latest Windows installer from the Releases section of this repository.

The application is free to use. No account or subscription is required for core local monitoring features.

## System Requirements

- Windows 10 or Windows 11
- Compatible NVIDIA graphics card
- NVIDIA graphics driver installed

Available monitoring measurements depend on GPU and driver support.

## Web Dashboard

RARA GPU Monitor includes an optional browser-based dashboard for local monitoring.

The web server can be enabled or disabled from application settings. Remote access requires appropriate network configuration and access protection.

## Privacy

GPU monitoring information is processed locally for core functionality. No developer-operated cloud connection is required for local monitoring.
